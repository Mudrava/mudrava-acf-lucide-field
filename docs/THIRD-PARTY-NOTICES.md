templates do not need CDN or API requests.

## Simple Icons

- Package: `simple-icons`
- Bundled version: `16.18.0`
- Source: https://simpleicons.org/
- Package license: CC0-1.0

The bundled `assets/brand-sprite.svg` file is generated from Simple Icons and
is used only for brand/logo values saved with the `simple:` prefix.

Simple Icons makes its package available under CC0-1.0, but this does not mean
every brand logo or trademark can be used without following the brand owner's
own rules. Brand names, logos, and trademarks may have separate guidelines,
license terms, or permission requirements. Check the relevant brand guidelines
before using a brand logo in production.

Source and guideline URLs included in the Simple Icons package are generated
into `data/brand-icons-meta.json`.
